# KAN Research Paper Project

This repository contains the research-paper materials and a from-scratch PyTorch re-implementation of Kolmogorov–Arnold Networks (KAN).

## Contents

- `2404.19756v5.pdf` — the KAN paper
- `KAN_Paper_Report_Detailed.pdf`, `KAN_Report_Detailed.docx` — project reports
- `KAN_Presentation_Detailed.pptx` — project presentation
- [`kan_code/`](./kan_code/) — implementation, experiments, tests, and generated results

For setup and reproduction instructions, see [`kan_code/README.md`](./kan_code/README.md).
